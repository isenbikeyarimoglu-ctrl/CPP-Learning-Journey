# 🚀 C++ Learning Journey

Welcome! 👋

This repository documents my journey of learning modern C++ through hands-on projects, coding exercises, and experiments.

Rather than only studying theory, I believe the best way to learn is by building. Every project in this repository focuses on applying new concepts in practice, improving both my understanding of the language and my software development skills.

---

## 📖 About

This repository is a collection of small projects that I build while learning C++. Each project explores one or more language features or programming concepts.

As I continue learning, this repository will grow with new topics, better coding practices, and increasingly complex projects.

My goal is not just to learn C++ syntax, but to understand how to design clean, maintainable, and efficient software.

---

## 🎯 Goals

Through this repository, I aim to:

- Build a strong foundation in modern C++.
- Learn new language features by implementing them in real code.
- Develop clean, readable, and modular programming habits.
- Improve software design and problem-solving skills.
- Practice version control using Git and GitHub.
- Document my progress throughout my learning journey.
